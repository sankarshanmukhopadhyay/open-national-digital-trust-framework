# ONDTF v0.7.0 — Implementation and Evaluation Draft

**Release date:** 12 August 2026

## Release summary

v0.7.0 moves ONDTF from an operational framework draft toward executable assurance. The release adds a deliberately minimal model-driven reference implementation, stable conformance assertion identifiers, evidence records, a clean-room implementation simulation, rights/remedy evaluation journeys, adversarial scenarios, and stronger implementation and assessor guidance.

Documentation becomes materially more navigable: controlled identifiers resolve through a generated Identifier Registry, while critical workflows use complementary flow, state and swimlane/sequence views so decision paths, lawful states and actor responsibilities can be understood independently.

## Evidence boundary

This release does **not** manufacture evidence that the repository does not possess. The clean-room implementation is a controlled simulation rather than an external implementer. The India profile still requires competent current legal review. URI-03, URI-04 and URI-14 are therefore narrowed and carried forward rather than falsely closed. v0.7.0 demonstrates the implementation-and-evaluation machinery needed to collect that evidence.

## Principal additions

- informative, non-production reference implementation driven by canonical lifecycle and authority models;
- executable, assessor-verifiable and judgement-dependent conformance assertion classes;
- canonical v0.7 evidence inventory and evidence-record schema;
- controlled clean-room implementation simulation and clarification register;
- rights/remedy journey harness including delegated AI action disputes;
- adversarial scenario catalogue;
- release-current TSMM and TIS compatibility review metadata;
- generated Identifier Registry and automatic published-page identifier linking;
- validation requiring unique, resolvable identifier anchors;
- complementary flow/state/swimlane documentation for provider lifecycle, authority delegation, challenge/correction and conformance assessment;
- implementation getting-started and assessor guidance.

## Next evidence gate

v0.8.0 should consume this machinery to obtain external independent implementation evidence, complete competent jurisdiction/sector review, execute adversarial exercises, and progress to cross-implementation interoperability, recognition and calibration evidence.
