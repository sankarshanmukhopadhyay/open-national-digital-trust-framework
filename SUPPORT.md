# Support

Use the support path that matches the request:

- **Defect, documentation error, or bounded enhancement:** open a GitHub issue.
- **Substantive normative or governance proposal:** open an issue first and describe the affected requirements, authority boundary, interoperability impact, and evidence needed to test the proposition.
- **Security or privacy vulnerability:** follow [SECURITY.md](SECURITY.md) and do not disclose exploitable details in a public issue.
- **Implementation/adoption question:** open a discussion or issue with the ONDTF version, profile, relevant requirement identifiers, and the implementation context.

This repository does not provide production operational support, certification, accreditation, legal advice, or a guarantee that a deployment conforms to applicable law. Repository maintainers can clarify the framework, its evidence, and its intended conformance model.
