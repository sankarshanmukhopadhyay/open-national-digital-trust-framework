# Normative requirements overview

ONDTF normative requirements are governed in the machine-readable `model/normative/requirement-catalogue.yaml` and published for readers through the [ONDTF Requirements Register](requirements-register.md).

The register is the preferred citation and navigation surface because every `ONDTF-*` identifier has a stable anchor and exposes the requirement's normative force, scope, assessed object, accountable and responsible roles, expected evidence, and candidate conformance assertion.

## How to use the requirements

1. Start with the [Requirements Register](requirements-register.md) when you encounter an `ONDTF-*` identifier.
2. Use [Requirements conventions](../normative/requirements-conventions.md) to interpret normative force and drafting rules.
3. Use [Applicability and scoping](../normative/applicability-and-scoping.md) to determine whether a requirement applies to a core, institutional, scheme, provider, interaction, affected-party or profile context.
4. Use [Profile requirement inheritance](../normative/profile-requirement-inheritance.md) to understand permitted specialisation and non-weakening.
5. Use [Requirements traceability](../normative/requirements-traceability.md) to follow requirements into evidence and conformance.

{: .note }
The human-readable register and this overview are coordinated views. The machine-readable requirement catalogue remains canonical.
