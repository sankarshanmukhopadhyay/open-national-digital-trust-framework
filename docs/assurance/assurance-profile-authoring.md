# Assurance profile authoring

A conforming assurance profile records the decision context, affected parties, Decision Impact Class, dimension-specific requirements, critical dimensions, freshness rules, failure actions, composition rule and bounded external mappings.

A conforming conclusion records required and achieved levels, evidence references, Evaluation Rigour Class, current state, blocking dimensions, validity and reassessment triggers. The schemas are `assurance-profile.schema.json`, `assurance-conclusion.schema.json` and `assurance-evidence.schema.json`.
