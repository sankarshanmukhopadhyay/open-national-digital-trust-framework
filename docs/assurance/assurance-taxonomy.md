# Assurance taxonomy

ONDTF separates six concepts that are often incorrectly collapsed.

| Concept | Meaning |
|---|---|
| Decision impact | Consequence if the trust decision is wrong, unavailable, unauthorised or unreviewable |
| Requirement | Evidence and controls demanded for a dimension |
| Achieved result | What the evaluated implementation demonstrated |
| Evaluation rigour | Confidence justified in the assessment method and assessor |
| Conformance | Whether named requirements were met |
| Assurance state | Whether reliance remains supportable now |

This separation prevents certification, authentication strength, maturity or a conformance pass from being represented as general trustworthiness.
