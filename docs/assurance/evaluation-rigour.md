# Evaluation rigour

Evaluation Rigour Classes ER-0 through ER-5 describe the assessment basis, from unassessed assertion to continuous evidence with independent oversight. The class records evaluator competence, independence, method, reproducibility, surveillance and change monitoring.

Accreditation, certification, testing, inspection, validation and verification are distinct conformity-assessment activities. A profile MUST identify which activity produced the evidence and MUST NOT treat the labels as interchangeable.
