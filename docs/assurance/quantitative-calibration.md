# Quantitative calibration

`CAL-001` separates **framework minimums** from **profile defaults** and **illustrative service objectives**. Current numerical values are deliberately labelled `provisional-internal-test-derived`; they are not promoted to core normative requirements.

Each parameter records its evidence basis, confidence and recalibration trigger. This prevents a convenient test value from silently acquiring policy authority.
