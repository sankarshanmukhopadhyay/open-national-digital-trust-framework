# Candidate normative inventory

The authoritative classification is `model/project/normative-document-manifest.yaml`. `NCP-001` through `NCP-005` identify candidate normative or profile-normative artefacts. Examples, reference code and implementation guidance remain explicitly non-normative.

Candidate requirement identifiers are frozen. Reuse of an existing identifier for materially changed semantics is prohibited by candidate change control.
