# Decision record

**Definition:** A durable evidence artefact that identifies a decision, its authority, inputs, applicable rules, outcome, time, and review or redress route.

| Property | Value |
|---|---|
| Identifier | `decision-record` |
| Classification | `governance` |
| Status | `active` |
| Normative | `true` |
| Owner | Specification Editorial Workstream |
| Aliases | decision receipt |
| External mapping | None |

## Scope note
