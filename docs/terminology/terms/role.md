# Role

**Definition:** A named set of responsibilities, permissions, constraints, and expected behaviours assigned to an actor within a governed context.

| Property | Value |
|---|---|
| Identifier | `role` |
| Classification | `governance` |
| Status | `active` |
| Normative | `true` |
| Owner | Specification Editorial Workstream |
| Aliases | None |
| External mapping | None |

## Scope note

This definition is authoritative within ONDTF. Applicability outside ONDTF requires an explicit mapping or adoption decision.
