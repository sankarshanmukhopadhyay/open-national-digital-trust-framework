# Conformance

**Definition:** The condition of satisfying specified requirements for a declared implementation, profile, process, or system.

| Property | Value |
|---|---|
| Identifier | `conformance` |
| Classification | `assurance` |
| Status | `active` |
| Normative | `true` |
| Owner | Specification Editorial Workstream |
| Aliases | None |
| External mapping | CTWG Glossary 1.4.1: `related` |

## Scope note

This definition is authoritative within ONDTF. Applicability outside ONDTF requires an explicit mapping or adoption decision.
