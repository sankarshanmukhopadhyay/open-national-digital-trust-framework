# Sector profile

**Definition:** A governed profile that applies ONDTF requirements to the risks, institutions, standards, and operating conditions of a defined sector.

| Property | Value |
|---|---|
| Identifier | `sector-profile` |
| Classification | `profile` |
| Status | `active` |
| Normative | `true` |
| Owner | Specification Editorial Workstream |
| Aliases | None |
| External mapping | None |

## Scope note

This definition is authoritative within ONDTF. Applicability outside ONDTF requires an explicit mapping or adoption decision.
