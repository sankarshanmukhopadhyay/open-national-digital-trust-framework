# Future work after v0.9.0

The candidate specification deliberately stops adding broad conceptual domains. Remaining work is evidence-led promotion toward v1.0.0:

- obtain externally operated independent implementation and interoperability evidence;
- obtain competent jurisdiction/sector review for any profile represented as reviewed or adopted;
- recalibrate provisional `CAL-*` values from measured operations and incidents;
- run external adversarial/resilience exercises and disposition findings;
- conduct structured candidate review across implementation, governance, rights, security, accessibility and legal perspectives;
- resolve `REV-*` comments and rerun affected conformance/interoperability evidence;
- promote only changes that satisfy candidate freeze/change-control requirements.

The v1.0.0 entrance gate is defined in [v1.0.0 Entrance Criteria](v1-readiness.md).
