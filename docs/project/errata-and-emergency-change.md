# Errata and emergency change

Candidate errata preserve the original release record and publish a traceable correction. Security or rights-critical emergency changes may use expedited authority only when purpose, scope, duration, evidence, review and termination are recorded consistently with ONDTF-GOV-006.

No erratum may silently reuse a normative identifier for materially different semantics. Breaking changes require a new identifier or an explicitly versioned migration rule.
