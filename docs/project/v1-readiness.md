# v1.0.0 entrance criteria

v1.0.0 requires evidence beyond the repository-local candidate package. At minimum: externally operated independent implementation evidence, competent jurisdiction/sector review where claimed, closure or explicit governance acceptance of remaining high-severity issues, review-comment disposition, stable conformance classes, and no unexplained critical traceability gaps.

The v0.9.0 candidate must therefore remain reviewable rather than prematurely declaring those external facts complete.
