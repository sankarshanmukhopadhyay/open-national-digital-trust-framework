# Candidate DTF package B

This second construction package exists to test question-set coverage, provenance, migration and deterministic validation against the v0.9.0 candidate question set. It is deliberately labelled a **construction simulation**, not an approved operational trust framework.

Its purpose is to prove that the candidate construction machinery can carry a second decision set without reusing the worked profile's decisions or claiming an authority that does not exist.
